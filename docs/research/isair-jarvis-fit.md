# isair/jarvis: перевірка придатності

Дата: 2026-11-10. Перевірений upstream commit: `f2b7e375be1579133bea4aa1306e09473f9c9a0b`. Статичний аудит README, Python-коду, CI та GitHub Releases; застосунок, моделі й інсталятори не запускалися. Висновки про фактичну швидкість або сумісність на конкретному Mac не є результатом тестування.

## Рекомендація

Зберегти native Swift VoiceLab і вже перевірений локальний ParakeetUK/CoreML шлях. Не замінювати весь проєкт форком isair: upstream оптимізовано під постійне слухання кімнати та multilingual Whisper, а наші жорсткі вимоги — виключно PTT, явно uk/en, без аудіохмари й підтвердження кожної зовнішньої дії. Розглядати код як референс для окремих MCP/черги задач/пам’яті; пряме запозичення також підпадає під ліцензію. Навіть executor не готовий до безпечного підключення без власного policy gate, журналу та протоколу скасування. Це оцінка архітектурного fit, а не виміряна оцінка трудовитрат.

## Перевірка тверджень звіту

| Твердження | Що справді підтверджено | Наслідок |
|---|---|---|
| Самостійний desktop GUI | PyQt6/WebEngine, PyInstaller `.app`, tray, чат, settings; packaged Apple Silicon існує | Повноцінний GUI, але інший Python/Qt стек, ніж поточний native Swift |
| Стабільний | Є тести, dated eval report, releases; README має known limitations. Надійність конкретного Mac/UK не виміряна | Слово «стабільний» не приймати як гарантію |
| Локальні STT/TTS | MLX Whisper / faster-whisper; Piper; Chatterbox лише source install | Локальний шлях реальний, але заміна нинішнього UK ASR не обґрунтована |

| NonCommercial / SourceAvailable | Власна Jarvis AI Assistant License | Personal/noncommercial fork дозволений з notices; derivatives мають ті самі умови; commercial/revenue use потребує окремої ліцензії |

## Критичні невідповідності нашим вимогам

1. **PTT.** Daemon безумовно створює і запускає `VoiceListener`; README описує rolling room transcript та wake-name. Dictation — окремий hold-to-record/release-to-paste шлях, а не PTT команди асистентові; double-tap активує hands-free. Pause Voice Listening існує, але це runtime control, не доведений fail-closed PTT-only startup invariant. Потрібно прибрати background listener, wake/hands-free, реалізувати command capture лише під час утримання та перевірити закриття мікрофонного stream на release/cancel. [src/jarvis/daemon.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/daemon.py) (1077–1134), [src/jarvis/dictation/dictation_engine.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/dictation/dictation_engine.py) (883–891, 1120–1203), [README.md](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/README.md).
2. **Мови.** Room listener MLX/faster-whisper і dictation передають `language=None`, тобто auto detect, а не явний uk/en. Це пряме порушення інваріанта нашого проєкту. `Settings` не має обмеженого UK/EN selector. Треба новий adapter contract із явним `uk`/`en`, тести обох шляхів, UK/EN-only output/TTS policy. [src/jarvis/listening/listener.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/listening/listener.py) (2583–2656), [src/jarvis/dictation/dictation_engine.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/dictation/dictation_engine.py) (1185–1203), [src/jarvis/config.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/config.py).
3. **Підтвердження відправлення.** ToolSpec містить name/description/inputSchema; ToolExecutionResult — success/reply/error/context/references. Немає execution approval token, immutable preview чи action risk field. MCP та builtins виконуються безпосередньо. Потрібен власний explicit preview → single-use user approval → execution gate, із revalidation перед side effect; prompt-інструкцій недостатньо. [src/jarvis/tools/registry.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/tools/registry.py) (ToolSpec; run_tool_with_retries), [src/jarvis/tools/types.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/tools/types.py).
4. **Скасування та аудит.** `TaskService.cancel` і `cancel_event` в reply pipeline є; task status/history зберігаються. Проте cancel не відкочує вже відправлений зовнішній side effect, а ToolExecutionResult/registry не доводять повний action audit із consent ID, аргументами, timestamps і результатом. Доопрацювати та перевірити окремо. [src/jarvis/tasks.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/tasks.py), [src/jarvis/reply/engine.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/reply/engine.py), [src/jarvis/tools/registry.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/tools/registry.py).
5. **Хмара й бюджет.** OpenAI-compatible backend із налаштованими URL/API key існує; endpoint отримує request text/context. Немає підтвердженого hard $10/month ledger/cap або local-simple/cloud-complex router, що відповідає нашим вимогам. Memory/embeddings і підготовчі LLM виклики також треба враховувати в витратах і дозволених data flows. Локальний audio→text, потім опційна text-only хмара — потрібна окрема перевірена межа. [src/jarvis/llm/openai_compatible.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/llm/openai_compatible.py), [src/jarvis/config.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/config.py), [README.md](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/README.md).
6. **Audio retention.** Переглянуті listener/dictation шляхи працюють із in-memory samples та локальним Whisper; очевидного запису вхідного WAV у них не знайдено. Dictation text history зберігається. Це не повний доказ відсутності аудіофайлів у всіх dependencies/diagnostics; вимогу «лише explicit one-shot diagnostic opt-in» слід встановити власним інваріантом. [src/jarvis/listening/listener.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/listening/listener.py), [src/jarvis/dictation/dictation_engine.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/dictation/dictation_engine.py), [src/jarvis/dictation/history.py](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/src/jarvis/dictation/history.py).

## Apple M1 / 16 GB / macOS 14.5

Реальний latest stable release за GitHub API на момент перевірки — [v2.8.0, 2026-10-19](https://github.com/isair/jarvis/releases/tag/v2.8.0), із `Jarvis-macOS-arm64.zip` (419,092,470 bytes). Це факт доступності asset, не підтвердження запуску на 14.5. HEAD і release можуть різнитися: цей code audit стосується pinned HEAD.

CI збирає arm64 на `macos-latest`, Intel на `macos-15-intel`, Python 3.11; requirements мають нижні, але переважно не верхні межі PyQt6/WebEngine/MLX. У переглянутих build/manifest немає explicit `LSMinimumSystemVersion`/`MACOSX_DEPLOYMENT_TARGET` чи matrix macOS14.5. Тому сумісність готового zip з фіксованою 14.5 **не встановлена**; без аналізу binary/dependencies або запуску не називати його сумісним. [.github/workflows/build-desktop.yml](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/.github/workflows/build-desktop.yml), [jarvis_desktop.spec](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/jarvis_desktop.spec), [requirements.txt](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/requirements.txt).

README враховує unified memory і memory budgets, але не дає виміряних M1 16 GB end-to-end p50/p95. Мета basic commands p50≤1s/p95≤2s залишається **не виміряною**. Upstream `EVALS.md` — dated model-behaviour evaluations із retries, не latency benchmark нашого PTT→ASR→executor→feedback. Поточні локальні 3/3 known-clip ASR результати нашого проєкту також не є повним command benchmark. [README.md](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/README.md), [EVALS.md](https://github.com/isair/jarvis/blob/f2b7e375be1579133bea4aa1306e09473f9c9a0b/EVALS.md).

## Що варто взяти як референс

- MCP discovery, persistent connection lifecycle, bounded request waits: `tools/external/mcp_runtime.py`, `mcp_client.py`.
- Task queue/status/persistence/cancel events: `tasks.py`.
- Tool schema/result boundary: `tools/registry.py`, `tools/types.py`, але додати policy/consent/cancellation/audit перед будь-яким side effect.
- Локальну diary/graph модель лише після появи реальної потреби; не вводити важку пам’ять у fast basic-command path.

Не переносити whole GUI/listener/Whisper stack лише заради executor. Власний мінімальний Swift command router і обмежені executor adapters мають менше несумісних defaults; складні text tasks можна підключити окремо з hard budget. Це рекомендація з аналізу коду, яку слід перевірити невеликим вертикальним прототипом і окремим versioned benchmark без перезапису історичних вимірювань.
