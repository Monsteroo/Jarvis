# Заміна ASR: локальні перевірки 10 листопада 2026

Користувач підтвердив фразу «Перемкнися на термінал» у другому з двох локальних діагностичних WAV. Невдалі base/small потрібно замінити. Аудіо не передавалося зовнішнім сервісам.

На цьому самому файлі, мова `uk`, поточний C-bridge, greedy decoding:

| Модель | Час inference | Висновок |
|---|---|---|
| Whisper base | 0,21 с, один запуск | Спотворює слова |
| Whisper small | 0,54 с, один запуск | Спотворює слова |
| large-v3-turbo-q5_0 | 2,20–2,57 с, три запуски | Спотворює дієслово й форму назви; ціль швидкості не виконана |
| large-v3-q5_0 | 3,03–3,19 с, два запуски | Назва програми краща, дієслово спотворене; ціль швидкості не виконана |

Це замір file-inference, не speech-end-to-action; розмір вибірки не дозволяє оцінити p95 або загальну точність. Перший WAV походить від попереднього набору підказок, тому його не використовуємо як доказ якості українських команд.

Контроль тракту: публічний JFK sample перетворено 16→48 кГц через ffmpeg, потім 48→16 кГц тією самою схемою AVAudioConverter/2048-frame chunks, що в AudioCapture. Повернуто 175994 семпли з очікуваних 176000 (різниця 0,375 мс). Base розпізнала текст правильно після конвертації. Це не виявило загального пошкодження конвертером на такому тесті, але не перевіряє фізичний мікрофон, драйвер або початок запису в реальній сесії.

Завантажені нові Whisper-моделі перевірено SHA-1 за upstream manifest:
- large-v3-turbo-q5_0: `e050f7970618a659205450ad97eb95a18d69c9ee`
- large-v3-q5_0: `e6e2ed78495d403bef4b7cff42ef4aaadcfea8de`

Вони не підключені до UI як рекомендовані заміни: на відомому записі переваги, достатньої для використання, не показали.

Альтернатива: [Parakeet UK](https://huggingface.co/ihnatov-yuri/parakeet-tdt-0.6b-v3-uk), донавчена на українській із збереженням англійської. Автор публікує власні результати на M3 Pro — вони не є доказом продуктивності на нашому Mac. [FluidAudio](https://github.com/FluidInference/FluidAudio) має macOS14 deployment target; реальну сумісність моделей перевіряємо окремо. Усі чотири int8 Core ML-компоненти завантажилися на macOS14.5. Фактичний результат inference наведено нижче.

Обмеження мов зберігається: лише українська та англійська. Скриптовий фільтр символів у FluidAudio не дорівнює гарантії мови вихідного тексту; багатомовний tokenizer не дозволяє обіцяти таку гарантію. Автоматичне виконання команд у цьому ASR-прототипі відсутнє.

## Результат і рішення

Parakeet UK розпізнала підтверджену фразу як «Перемкнись на термінал» у 6/6 запусків пробного декодера (CPU/ANE). Після інтеграції в native `Sources/Parakeet.swift`, той самий WAV правильно розпізнано 3/3: **456,6 / 378,0 / 330,5 мс**. Одноразове завантаження — 3,63 с; модель залишається у пам’яті. Англійський публічний JFK sample розпізнано правильно, 547,2 мс inference. Це мала контрольна вибірка, не доказ загального SLA або 90% точності.

Вибрана CPU-конфігурація: Neural Engine на пробному декодері не показав значущого виграшу на короткій фразі й потребував близько 31 с першої підготовки. Новий native декодер обмежує символи залежно від явно обраних `uk/en`; український режим допускає латинські назви програм. Це не повна гарантія мови слів зі спільними літерами. Докладний probe: `parakeet-probe.md`.

У Jarvis модель Parakeet UK вибрана за замовчуванням, Whisper base/small залишені для порівняння. Core ML модель має фіксований вхід 240000 samples, тому захоплення обмежене 15 секундами (без мовчазного обрізання). Контроль скасування діє між синхронними Core ML predictions; поточна prediction завершується перед зупинкою. Потрібен наступний живий прохід українських фраз із новою моделлю.
