# Jarvis visual concepts

Generated 10 November2026 with the built-in image generation tool. These are design mockups, not screenshots of implemented UI; task states and microphone states are illustrative. Final UI states must follow actual audio/task events. The app supports Ukrainian and English.

- [ARC](./jarvis-arc-concept.png): cinematic cyan/amber reactor, incomplete concentric arcs, task progress rail, dark precision HUD.
- [PRISM](./jarvis-prism-concept.png): dark spatial glass, sculptural liquid-light loop, restrained native navigation, task column, compact voice island.

Recommendation for user's cinematic direction: ARC, with a coherent native main window and compact HUD. Final selection is pending user feedback.

Implementation reference: [release design](../superpowers/specs/2026-11-10-jarvis-v0.1-design.md). Images convey materials, composition and visual identity; implement the core as code-native graphics that react to live input, not as a static raster background pretending to listen.
